CityFFD2.1 User Guide
=====================

This guide describes the input files, configuration parameters,
and basic workflow for CityFFD2.1.

Example settings illustrate the input structure and are not
universal defaults. Users should select appropriate numerical
settings and assess solution convergence and accuracy for their
applications.
