How to Use This Guide
=====================

Start with :doc:`quick_start` for the required directory structure
and the basic workflow.

Then review :doc:`parallel_gpu` to configure computational resources
and check the runtime requirements.

Use the following sections to define the geometry and mesh,
numerical controls, boundary conditions, velocity profiles,
and meteorological inputs.

Consult :doc:`thermal_coupling` when configuring coupled simulations,
and :doc:`output_probes` to set up field output and probe measurements.

For existing CityFFD2.0 configurations, refer to :doc:`migration`
before updating the input files.

Scope
-----

This guide describes the input files, configuration parameters,
and basic workflow for CityFFD2.1.

Example settings illustrate the input structure and are not universal
defaults. Users should select appropriate numerical settings and assess
solution convergence and accuracy for their applications.
