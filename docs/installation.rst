Installation
============

System Requirements
-------------------

CityFFD2 requires an NVIDIA GPU.

The recommended software environment includes:

* Linux
* NVIDIA HPC SDK
* CUDA
* MPI
* NCCL


Compilation
-----------

The compilation instructions for CityFFD2 will be provided here.


GPU Requirements
----------------

CityFFD2 uses one MPI process per GPU.

For example, four MPI processes normally correspond to four GPUs.
